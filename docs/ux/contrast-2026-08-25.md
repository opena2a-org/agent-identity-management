# Contrast receipt: dashboard readability (2026-08-25)

Measurements behind the change that re-tuned the light-theme text tokens, scoped the
code-block tokens to the contrast surface, added the SDK install link to the dashboard
Quickstart, and grouped the agent detail tabs. Thresholds are WCAG 2.x: 4.5:1 for body
text, 3:1 for large text. Every ratio below was produced by one of the two instruments
named in "Reproduce"; nothing is estimated.

## Method

- **Static composite.** Token values from `apps/web/app/globals.css` are alpha-composited
  (src-over) onto the page colour (`#e9eef7` light, `#131318` dark) and the WCAG relative
  luminance ratio is computed. Backdrop blur is not modelled, so this is the design-time
  bound; the live sweep is the closing check.
- **Live sweep.** Chrome (playwright-core), 375x812 and 1280x800, light and dark (`dark`
  class on `<html>`), computed colours normalised through a canvas, every visible text
  node sampled. Auth-gated routes are rendered behind a mocked `/api/v1` so the dashboard
  and agent detail page can be measured as a signed-in admin sees them.

Instrument caveat, unchanged from the audit: the sweep reads the nearest ancestor
`background-color` without compositing a translucent tint over its parent, so the
`bg-brand-soft` note boxes on register and forgot-password report 2.04 (light) / 1.19
(dark). Their composited value is 7.57 / 5.38 (pass); those rows are excluded above and
the mocked-render script composites ancestors correctly.

Rows the sweep still reports that are outside this batch (audit items 7 and 10): 12px
body text on register, forgot-password and device at 375px; the 16x16 "Show password"
control; the 127x20 "Back to Sign Up" link on privacy and terms.

## Mocked-API live render, gated routes

`/dashboard` (zero agents) and `/dashboard/agents/<id>` rendered on the branch dev
server as a signed-in admin (unsigned JWT in the auth cookie and localStorage; every
`/api/v1` request served by shape-correct fixtures derived from `lib/api.ts`; agent
fixture: verified, trustScore 0.82). 2 routes x 375x812 and 1280x800 x light and dark.
The render script drives system Chrome over the dev server, mocks every `/api/v1`
route with shape-correct fixtures, composites each text node's background up the
ancestor chain, and reports WCAG ratios; the tables below are its output.

| Run | Text pairs sampled | Min ratio | Pairs below threshold | Horizontal overflow |
|---|---|---|---|---|
| dashboard 375 light / dark | 82 | 4.68 / 4.70 | 0 / 0 | none |
| dashboard 1280 light / dark | 78 | 4.68 / 4.70 | 0 / 0 | none |
| agent 375 light / dark | 158 | 1.53 / 3.83 | 1 / 1 | none |
| agent 1280 light / dark | 154 | 1.53 / 3.83 | 1 / 1 | none |

The one remaining pair on the agent page is the disabled "Verified" action button
(white on brand at `opacity: 0.5`, 1.53 light / 3.83 dark). WCAG 1.4.3 exempts
inactive controls, so it does not gate this change; a disabled button used as a
status display is a known follow-up. Before this change the same render
showed 11 failing pairs (light) and page `scrollWidth` 463 at a 375 viewport.

Also measured in the render:

- Quickstart code (`.glass-contrast pre.code-block`): 10.02 light / 10.96 dark;
  `$ ` prefix 8.09 / 8.85; the FirstAgentCard block 14.85 / 14.34.
- "Install the SDK": two anchors with `href="https://pypi.org/project/aim-sdk/"`
  (Quickstart and FirstAgentCard), white on brand 4.7.
- Tab strip: 4 tabs (Overview, Connections, Security, Access); inactive 5.06 light /
  6.33 dark, active 16.61 / 8.95; at 375 the strip is 343 px wide, last tab right
  edge 356 px, no internal overflow.
- Deep links: `?tab=violations` and `?tab=key-vault` select Security, `?tab=trust`
  Overview, `?tab=connections` Connections; in all 16 loads the named section is
  scrolled to (target top 15.6-87.3 px inside the viewport).
- Console: no page errors; the only console lines are the two 404s designed into
  the fixture for `capabilities/latest`.

Not covered by the render: real backend response shapes, backdrop-blur compositing
(first-stop approximation on gradients), the security and executive lens variants,
and non-empty states for MCP servers, alerts, violations, activity, API keys, tags.
