# Contrast receipt: route sweep (2026-10-05)

Closing readability sweep of every dashboard route, run with the instrument this
document names. Nothing below is estimated; every figure is copied from the
instrument's result file. No finding is fixed here: this is the measurement.

## Instrument

- Script: `apps/web/scripts/ux-sweep.mjs`, committed together with this document.
- Tree measured: the dashboard was built from the main branch as it stood before the
  dashboard route moves, with the change "Sign-up, reset and device sign-in text reads
  at 14px or larger, and Show password is a 44px tap target" applied. That tree is not
  a commit of this history: here the route moves, the first-run steps on the agent
  page, the Verified status badge and the Next.js 16.3.6 update come before that
  change, so the commit that carries it has 33 routes, not the 35 measured. The
  instrument ran at the version committed with this document. Four routes of the
  measured tree have since moved and are redirects now: `/dashboard/admin/compliance` to
  `/dashboard/compliance`, `/dashboard/api-keys` and `/dashboard/sdk-tokens` to
  `/dashboard/credentials`, and `/dashboard/agents/[id]/success` to the agent's page.
  Their rows below measure those pages as they were; `/dashboard/compliance` and
  `/dashboard/credentials` are not measured in this run.
- Run: started 2026-10-05T06:27:49Z, finished 2026-10-05T06:32:50Z, exit code 1
  (the gate below failed).
- Browser: Chromium through Playwright 1.59.1 (the `@playwright/test` dev dependency
  of `apps/web`), headless.

## Method

- **Routes.** Every `page.tsx` under `apps/web/app` is enumerated from the tree:
  35 files, 35 routes. The dynamic segment `[id]` is loaded with the fixed value
  `00000000-0000-4000-8000-000000000001`.
- **Variants.** Each route is loaded at 375x812 and 1280x800, in the light and the
  dark theme (`theme` in localStorage, read by next-themes; the instrument records
  whether the `dark` class was applied, and it was in all 70 dark loads): 140 loads.
- **Session.** An unsigned session token with `role: admin` is placed in
  localStorage before any script runs; the dashboard only decodes it. Every
  `/api/v1/**` request is answered by the route mock inside the instrument, with
  response shapes taken from `apps/web/lib/api.ts` (empty collections, one sample
  agent and one sample MCP server). The result file lists any request the mock did not
  recognise; in this run that list is empty.
- **Contrast.** Every visible text node is sampled. The foreground is the computed
  `color`; the background is every ancestor's `background-color` composited
  src-over from the document (white) down to the element. A gradient background
  contributes each colour stop, and the ratio is taken against the worst stop;
  an opaque layer closer to the text resets the chain. Text over a url() image is
  reported as unmeasured (none in this run). Large text is 24px, or 18.66px at
  weight 700 and above. Thresholds are WCAG 2.x: 4.5:1 body, 3:1 large.
- **Other counts.** Visible text nodes under 14px; interactive targets (links,
  buttons, inputs, selects, ARIA widgets, focusable elements) whose box is under
  44x44 CSS px, with links inside running text exempt as in WCAG 2.5.8; presence of
  a `<main>` landmark; horizontal overflow as the document's scroll width minus
  its client width; console messages of type error and uncaught page errors.
- **Not modelled.** Overlapping layers that are not ancestors (a positioned card
  over a sibling), ancestor `opacity`, and backdrop blur. The ratios are the
  ancestor-composited bound.

## Reproduce

From the repository root, with `apps/web` dependencies installed:

```
npm --prefix apps/web run build
npm --prefix apps/web run start -- -p 3100
node apps/web/scripts/ux-sweep.mjs --base http://localhost:3100 --out /tmp/ux-sweep.json
echo "exit $?"
```

The script prints one line per load and the gate summary, writes the result file,
and exits 1 when any route fails a gated criterion. If Playwright reports that
Chromium is missing, install it once with `npx playwright install chromium`
(inside `apps/web`). The per-route table above is the `routes` array of the result
file; the sample table is `worstBody` and `worstLarge` of each entry in `variants`.
