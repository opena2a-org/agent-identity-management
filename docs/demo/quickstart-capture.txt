You can now use the AIM SDK. Register an agent, then protect any
function with a capability grant:

   from aim_sdk import secure

   agent = secure('my-agent', capabilities=['db:read'])

   @agent.perform_action(capability='db:read')
   def get_customer(customer_id):
       return db.query('SELECT * FROM customers WHERE id = ?', customer_id)

Every @perform_action call is signed, checked by the server against the
agent's granted capabilities and your organization's security policies,
and recorded in the audit log. In strict enforcement mode, calls outside
the granted capabilities are denied unless a security policy allows
them; in monitoring mode, the default, they run and are recorded. An
administrator turns strict mode on with Global Enforcement Mode on the
dashboard page /dashboard/admin/security-policies.
